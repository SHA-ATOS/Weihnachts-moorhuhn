# 🎄 Weihnachts-Moorhuhn 🎄

Ein weihnachtliches Moorhuhn-Schießspiel für 2 Spieler im Browser!

## 🎮 Spielanleitung

**Spieler 1 (Rot):** Maus bewegen + Linksklick zum Schießen  
**Spieler 2 (Blau):** Pfeiltasten bewegen + Leertaste zum Schießen

### Punkte
| Ziel | Punkte |
|------|--------|
| 🐔 Kleines Huhn | 10 |
| 🐓 Großes Huhn | 5 |
| ⭐ Stern | 25 |

### Zeitlimit
Das Spiel dauert **60 Sekunden**. Wer am Ende die meisten Punkte hat, gewinnt!

## 🚀 Starten

Einfach `index.html` im Browser öffnen – keine Installation notwendig!

## Features

- 2-Spieler-Modus (gleichzeitig spielbar)
- Weihnachtsmarkt-Hintergrund mit Buden, Lichterketten und Weihnachtsbaum
- Schneefall-Effekt
- Verschiedene Zieltypen mit unterschiedlichen Punkten
- Animierte Moorhühner mit Weihnachtsmützen
- Schuss- und Treffer-Effekte
- Countdown-Timer
